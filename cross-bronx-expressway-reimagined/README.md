# Cross-Bronx Expressway 重新想像・前後平面圖對比

單一自足的互動式 HTML 頁面，以平面圖比較 Cross-Bronx Expressway(I-95)在 Starlight Park／
Bronx River 一帶的現況,與「Reimagine the Cross Bronx Expressway」願景報告(2025年3月)提出
的加蓋覆土公園段概念。

打開方式：直接用瀏覽器開啟 [`index.html`](index.html),不需安裝、不依賴外部 CDN。

## 與日本橋那頁的關鍵差異(請注意)

這不是「地下化」案例,而是「加蓋(capping)」案例：公路本身不會遷移或拆除,只是在部分路堑
段上方加蓋覆土,做成公園/ 綠地。頁面用詞刻意避開「規劃」「預定」等暗示已定案的字眼,改用
「願景概念」「非定案」,因為：

- 這個案子目前(2026年9月)仍停留在願景/研究階段,**官方尚未公布任何動工或完工時程**,
  跟日本橋地下化(已有 2035／2040 官方目標年度)性質不同。
- 2024年10月 NYC DOT 一次發表了 13 項提案,涵蓋全線多個路段;本頁畫面只挑其中一段
  (Starlight Park 附近)做**示意繪製**,加蓋範圍是本頁自行選取的示意位置,並非官方定案
  地點。

## 功能

同日本橋那頁的互動邏輯：現況／願景概念切換、左右拉桿比對、圖層核取方塊(知名地標與設施／
加蓋覆土公園段／自行車人行連結／文字標籤),狀態即時同步到網址參數(`state`／`landmarks`／
`cap`／`bike`／`labels`／`compare`／`pos`)。下方附時間軸,涵蓋公路本身的興建歷史、鄰近
已完工的 Sheridan Boulevard(2019)／Starlight Park(2023)案例,以及這次願景規劃的推動
過程。

## 資料限制

這次工作環境的對外網路政策封鎖了 OpenStreetMap、Google Maps、Wikipedia 等地圖資料源
(`curl`／`WebFetch` 皆收到 403/EGRESS_BLOCKED),也連不進 `crossbronx.info` 官方網站本身,
因此**無法取得官方提案地圖或實測建物輪廓**。街廓、建物量體、公路與河道線形是依網路搜尋
取得的官方新聞稿與媒體報導文字內容(見頁尾連結)手繪重建的示意圖,細節已簡化,非測量成果。
