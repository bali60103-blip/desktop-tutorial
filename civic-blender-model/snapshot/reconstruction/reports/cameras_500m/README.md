# 市民大道每500m南北向相機

已建立22組、44台相機：0、500…10000m共21站，另加東端10395.046m一站。每組同位置、相反方向，水平朝真北／真南（由經緯度投影計算），28mm鏡頭、36mm感光面寬，模型地表上1.7m。

里程是以具名一至八段地面OSM路線，在TWD97每10m東向採樣兩側車道北向座標中位數，產生由西至東分析軸；不是測量中線或官方工程里程。全段推導长度10395.046m，不累加雙向車道長度。局部採樣最大間距30.344m，代表曲線／兩側車道差異，需精確里程時應以正式道路中線替換。

Blender集合：`CIVIC_CAMERAS_500M_NORTH_SOUTH`。名稱如`CIVIC500_01K000_N`、`CIVIC500_01K000_S`，N朝北、S朝南。時間軸frame1為0m北、2為0m南、3為500m北，依序到44為東端南。切換對應影格即可切鏡頭。相機自訂屬性保存里程、經緯度、路段及地表取樣狀態。

44鏡頭朝向、22組同位置反向、每500m站距檢查通過；44張960×540預覽已生成。抽看1K南北、6K北、10K北，鏡頭切換有效；東段缺少背景建物反映目前模型不足，不能解讀為現實空地。

6K000及6K500未命中已建地表面，暫採Z=0+1.7m，4台相機已標記。30m正前方橋柱射線未命中，不等於整個視錐無遮擋；此檢查未涵蓋建物、植栽與其他構件。原第04／05段地下樣板及7組衝突仍保留，未將相機完成等同C關卡通過。

模型、原始站位軸及44張圖保存在本機；GitHub保存腳本、輕量站位清單、驗證與雜湊，未上傳.blend。
