## 座標收斂後的估算做法
1. 鎖定核對過的地面控制點、座標轉換與平面輪廓，保留來源年代。
2. 對仍缺資料項目列參數表：採用值、依據、替代方案、合理變動範圍；無法判定誤差時填未知。
3. 估算高度、板厚、坡度與構件尺寸各自標記，不把示意圖或入口限高當樓高。
4. 先做一段地上地下完整樣板，檢查路口、人行道、樓梯、坡道及柱位碰撞，再推廣全段。
5. 關卡可記「工作模型完成、部分尺寸估算」，不可記作已驗證竣工還原；A–E 按既定流程保存模型快照及 GitHub 清冊。
