# 已開始實體細部建模：中林段人行道

原工作表第 03 段的地面構件進入細部試作；並非關卡 B 已完全通過，也不是地下／高架完整還原。

## 實體成果
- 6 個官方人行道來源圖形，聯集範圍約 3462.46 m²。
- 643 塊分段路緣石、20169 塊鋪面磚；合併成 2 個網格物件以控制效能。
- 每塊有厚度及接縫，並非平面參考曲線或材質貼圖。
- 不在裁切範圍邊界新增假路緣；臨車道方向依 OSM 車道參考線判別，仍須現況核對。
- 全部新實體以官方 XY 為基底；構造尺寸、鋪法與材料色彩為估算。既有人行道基底保留，新鋪面由模型 Z=.15 至 .17 m，路緣石由 Z=0 至 .17 m。

## 估算參數
磚尺寸 .6×.3 m，厚 .02 m，接縫 .006 m；路緣寬 .15 m，高 .17 m；鋪法角度 -4.6°。這些不是實測。全球高程基準仍未知，不能將模型 Z 當海拔。來源座標的轉換已沿用既有核對結果，這不代表全段所有座標問題均已解決。

## 驗證
生成時檢查三角面積損失；匯入後焊接頂點、重算面法向。初次發現裁切磚平面小孔，已修正並要求非流形邊為零才存檔。最終結果見 mesh_check.json。已渲染一般及近接縫視角，近景可辨識磚縫與路緣分段。

## 尚未完成與下一步
入口樓梯、無障礙坡道、觸覺引導、排水口、樹穴與道路標線尚未定位或新增。現階段路緣為工作模型候選，可能需要在既有無障礙通道處切開，不可據此判斷現場通行障礙。下一步以入口與道路交界資料安排開口，並逐步補齊路面細節；地下和真實柱位照原順序核對。
