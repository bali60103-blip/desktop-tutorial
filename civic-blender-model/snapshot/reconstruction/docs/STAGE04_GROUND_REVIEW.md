# 中林地面檢核：Stage04

完成 22 個官方人行道輪廓裁切、3 個 OSM 路口參考點及 Blender 疊圖。

這是既有模型的檢核集合，不是新增第二套人行道實體。輪廓的 Z=0.6 公尺僅供顯示，不代表路緣高度。中山北路參考點採東側車道與市民大道兩方向路名線端點之平均；天津街、林森北路亦採兩個實際相接點平均。這些點不是測量控制點或路口中心。

## 查核結果與待改善
- 官方設施多邊形在本次範圍只有 1 個座椅物件，沒有樓梯資料；這是資料覆蓋不足，不能判定現場沒有樓梯。
- 官方停車場示意圖支持：1 號樓梯在中山北路至天津街之北側；2 號在該街廓南側；3、4 號在天津街至林森北路南側。精確 XY 仍為未知。
- 人行道圖中有狹縫與邊界轉折，未經定位影像核對，不能直接認定是停車場樓梯。
- 工程文獻 PDF 第 13 頁的地下街層高 5.7 / 5.4 公尺描述含商業公共通道的共構配置，未證明適用中林 B1/B2 停車場，未套入模型。
- Gate B 仍待入口定位、圖面尺度、高程驗證；不在本次新增地下或楼梯實體。

## 下一建模關口
取得四座樓梯的可定位影像／測量點，對比人行道開口；取得尺寸控制後才建立樓梯及地下板。可獨立推進的下一項是第一排建物輪廓與 OSM 高度標籤的稽核，未知高度須明確標示。
