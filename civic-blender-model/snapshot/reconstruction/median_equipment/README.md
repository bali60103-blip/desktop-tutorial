## 模型更新門檻
1. 對每個箱體取得路口、橋柱、坡道等至少兩項對位線索，確認位於地面層。
2. 平面尺寸優先採測繪圖或可定位建物輪廓；照片需透視校正，不能以近景汽車去量遠景箱體。
3. 高度以同深度且已知尺寸的參考物校準；沒有尺度時以範圍記錄，保留估算標記。
4. 設備外殼、矮牆、植栽槽分開建模，維修空間與實體占地分開。
5. 輸出設備占地率、可通行淨寬和視線遮擋，輔助南北分隔分析。只可證明物理障礙，不能單靠設備存在推論產業差異的原因。

## 本輪模型狀態
本輪完成來源及設備清單，未把缺乏座標、尺寸的設備強行放進主場景。既有模型保持原狀。
詳細設備表見 median_equipment_inventory.json；OSM候選仍須核對現場，資料無標記不代表現場無設備。
