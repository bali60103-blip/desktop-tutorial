# 衝突柱位與匝道影像校準

使用者確認範圍為匝道分流及合流段，順序為先柱位後匝道。
7組衝突柱位：036、114、408、438、534、540、674。
本輪已轉換座標並生成街景/衛星核對連結；未移動模型。
現有官方墩柱點距各組柱帽中心最近約80至1188m，不能認定同一橋柱。
街景頁面可開啟，但當前工具僅回傳頁面文字，沒有可供目視量測的影像；尚未取得修正依據。
衝突可能源自估算坡道、斑馬線或分隔島，不預設橋柱必須移動。
修正時要核對柱腳與道路邊線、坡道口、鄰柱至少兩組固定參照；記錄影像日期與修正前後座標。
匝道平面可用衛星或官方正射影像核對。正射影像是航空影像，不標成衛星。
官方可用影像服務來源：https://www.nlsc.gov.tw/cp.aspx?n=16732
不能從俯視圖直接取得橋下柱位、梁底或匝道高程。主場景修改需另存快照並檢查橋面連續、柱帽支承、坡道碰撞。
