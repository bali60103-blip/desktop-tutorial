# 基地分析:市民大道西段—華山大草皮

基地:市民大道西段到華山大草皮,沿線 2 公里緩衝範圍(使用者於對話中確認)。
四項分析:

1. 周圍綠帶體量分析(`analysis1_green_volume.py`)
2. 代表基地特色的街區(`analysis2_block_character.py`)
3. 綠帶連結延平河濱公園可行性(`analysis3_riverside_connectivity.py`)
4. 基地附近人潮聚集地點與功能(`analysis4_crowd_hotspots.py`)

## 執行方式

```bash
pip install -r ../../requirements.txt
cd src/site_analysis
python run_all.py
```

輸出:
- `../../data/processed/*.geojson` — 各分析裁切後的圖層(可另外用 QGIS 等工具開啟)
- `../../data/processed/analysis{1..4}_summary.json` — 每項分析的統計摘要
- `../../output/site_overview_map.html` — Leaflet 總覽地圖(用瀏覽器開啟)

原始資料放在 `../../data/raw/`(已加入 .gitignore,不會進版控,體積較大)。

## 重要限制與待確認事項

**基地範圍本身有兩個未經資料驗證的假設**,見 `config.py` 開頭註解:
- 市民大道西端座標是從 OSM 匯出資料反推的
- 華山大草皮座標是公開常識估計值,**沒有任何提供的資料集包含這個座標**

**各分析的資料缺口**(每支分析腳本開頭都有更詳細的說明,這裡列重點):

| 分析 | 缺口 |
|---|---|
| ① 綠帶體量 | 沒有樹冠寬度資料,只能算株數/樹高分布/面積,不是真正的三維體積 |
| ② 街區特色 | **沒有建物 footprint / 地籍資料**,只能用土地使用分區 + 建照點位推論,不是完整街廓分析(使用者已表示會另外補建物資料) |
| ③ 河濱連結可行性 | 沒有路網 graph,用「假想直線 + 300m 緩衝」做粗略訊號,不是真正的路徑可行性分析;延平河濱公園只有中心點座標,沒有邊界 |
| ④ 人潮聚集地點 | 沒有百貨/夜市/宗教場所/體育館等 POI 名單,沒有公車站牌資料,只能用捷運站+停車場+市場/機關/文教/學校用地分區作間接指標 |

**取捨/資料品質問題**(處理過程中發現,已在程式碼註解記錄):
- 都市計畫主計圖/細計圖的「細部計畫範圍」邊界線在原始 shapefile 裡是無效幾何
  (純內環、面積算出來是天文數字),已在 `analysis2/4` 中排除,不計入分區統計
- `park06` 檔名雖像公園資料,實際是停車場出入口勘查照片點位,未使用
- `TP_TREE.json`(檔名像行道樹清冊)實際是花圃/植栽帶多邊形,沒有樹高欄位;
  已改用 `TaipeiTree_1.csv`(有樹高)做行道樹分析,`TP_TREE` 未使用
- `I03015.geojson` 全部 49 筆都是空名稱、0 面積,沒有實質內容,未使用
- `L03011.geojson`(93,664 筆點位)ID 格式跟 `TaipeiTree_1.csv` 很像但缺樹種/樹高
  屬性,懷疑是同一批樹木普查的另一種匯出,未使用(避免跟 CSV 版本重複計算)
