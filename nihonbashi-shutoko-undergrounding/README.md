# 日本橋首都高地下化・前後平面圖對比

單一自足的互動式 HTML 頁面，以平面圖（plan view）比較首都高速道路「日本橋区間地下化事業」
的現況（高架橫跨日本橋川／日本橋上空）與規劃完成後（高架拆除、道路地下化、水岸重見天空）。

打開方式：直接用瀏覽器開啟 [`index.html`](index.html)，不需安裝、不依賴外部 CDN。

## 功能

- **現況 Before／地下化後 After** 切換,或按「左右拉桿比對」用可拖曳分隔線同畫面比較。
- 四個獨立圖層核取方塊(知名地標建物／沿岸再開發街廓／親水步道與植栽／文字標籤),可依需要
  疊圖或關閉,呼應「依參數疊圖」的需求。
- 所有畫面狀態即時同步到網址列查詢參數(`state`／`landmarks`／`redev`／`riverwalk`／
  `labels`／`compare`／`pos`),可直接分享特定疊圖組合的連結,例如:
  `index.html?state=after&compare=1&pos=30`。

## 圖面內容取材

- 地下化區間、時程等數字(神田橋JCT⟷江戸橋JCT 約1.8km、其中1.1km地下化、2035年度地下
  新路線通車、2040年度全案完成、日本橋リバーウォーク約1.2km×約100m 親水空間等)已透過
  網路搜尋比對首都高速道路株式会社、東京都都市整備局、国土交通省及多家媒體報導查核,頁尾
  附完整連結。
- 街廓、建物量體、道路與河道線形屬**手繪示意重建**,依日本橋地區公開且穩定的地理常識(中央
  通りと日本橋川的相對位置、三井本館・三越本店・日本銀行本店・COREDO日本橋・日本橋高島屋
  S.C.等地標建物方位)繪製,**並非實測 GIS/向量圖資**。

## 資料限制(為何不是實測底圖)

這次任務執行環境的對外網路政策封鎖了 OpenStreetMap(`overpass-api.de`、
`nominatim.openstreetmap.org`)、日本国土地理院地図(`gsi.go.jp`)、Wikipedia/Wikimedia,
甚至首都高速道路官方網站 `shutoko.jp` 本身(`curl` 與 `WebFetch` 皆收到
`403`/`EGRESS_BLOCKED`),因此**這次工作階段無法抓取任何實測建物輪廓向量圖資**當底圖。

頁面本身與本檔案都已註明此限制。如需用於實際規劃比對、簡報或發布,請將本頁的街廓/建物
量體置換為首都高速道路株式会社、国土交通省或東京都公告之正式測繪圖說,再校正座標與比例。

## 延伸使用

`index.html` 內的資料結構(`RIVER_LEFT`/`RIVER_RIGHT`/`LANDMARKS`/`REDEV` 等陣列)與圖層
疊圖機制,設計上可直接複用同一套版型繪製 Cross-Bronx Expressway 或 West Side Highway 的
前後平面圖對比 —— 只需替換座標資料與地標清單。
